## 📱 주요 기능

- **오늘의 말씀과 기도** — 매일 새로운 말씀과 추천 기도문
- **설교 녹음 & 자동 전사** — 예배 말씀을 녹음하고 텍스트로 변환
- **마음돌봄** — 신앙 고민 AI 상담
- **나눔기도** — 셀모임 나눔질문·기도제목 도구
- **묵상 기록** — 나만의 묵상 노트 보관

## ❓ 자주 묻는 질문

### Q. 녹음 전사가 안 돼요.
- 무료 사용자는 월 10분, 단일 녹음 10분까지 전사 가능합니다.
- 한도 초과 시 다음 달까지 기다리거나 프리미엄 플랜으로 확장할 수 있습니다.

### Q. 마음돌봄 상담이 안 돼요.
- 무료 사용자는 하루 1회 상담 가능합니다.
- 자정 이후 다시 사용 가능합니다.

### Q. 녹음한 파일은 어디에 저장되나요?
- 모든 녹음 파일은 사용자의 기기에만 저장됩니다.
- 전사 완료 후에도 원본 녹음은 기기에 보관됩니다.

### Q. 데이터가 다른 기기로 옮겨지나요?
- 현재 버전(v1.0)은 단일 기기 저장만 지원합니다.
- 향후 업데이트에서 데이터 동기화 기능을 추가할 예정입니다.

### Q. 마음돌봄에서 위기 상황 안내가 떴어요.
- AI 상담은 전문 상담을 대체하지 않습니다.
- 위기 상황에서는 자살예방상담전화 **1393** 또는 **119**로 연락해 주세요.
